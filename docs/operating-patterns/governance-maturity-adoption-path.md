# Governance Maturity Adoption Path

## Purpose

This document defines how operational systems progressively mature within ARI governance.

---

# Maturity Path

```text
Unmanaged
-> Observable
-> Governed
-> Continuity-Aware
-> Trust-Aware
-> Operationally Resilient
```

---

# Stage 1 — Unmanaged

Characteristics:

- weak lineage
- implicit trust
- unknown rollback capability
- limited runtime visibility

---

# Stage 2 — Observable

Characteristics:

- entities identified
- operational events visible
- runtime systems identifiable

---

# Stage 3 — Governed

Characteristics:

- governance contracts applied
- runtime projections defined
- rollback boundaries visible
- trust boundaries defined

---

# Stage 4 — Continuity-Aware

Characteristics:

- replay visibility exists
- semantic continuity preserved
- reconciliation workflows defined
- operational causality visible

---

# Stage 5 — Trust-Aware

Characteristics:

- trust propagation modeled
- canonical promotion governed
- trust degradation visible
- recovery trust explainable

---

# Stage 6 — Operationally Resilient

Characteristics:

- continuity preserved across mutation
- governance-aware recovery exists
- runtime reconciliation is explainable
- operational graph reasoning is possible

---

# Significance

This maturity path demonstrates that ARI adoption can evolve progressively rather than requiring fully mature governance immediately.
